# LinesiaPack

Le resource pack du serveur Minecraft Bedrock **Linesia** (`play.linesia.net`) :
textures, modèles, objets, blocs, particules et textes du serveur.

Le serveur l'envoie tout seul à la connexion, rien à installer.

## Contenu

- `textures/` : blocs, objets, entités
- `models/`, `attachables/`, `entity/`, `animations/`, `animation_controllers/`, `render_controllers/` : modèles 3D et animations
- `particles/` : effets
- `texts/` : noms et descriptions en français, anglais, espagnol, allemand et italien
